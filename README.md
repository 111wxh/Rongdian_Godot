# 《融点》RONGDIAN — Godot 4 可玩原型

冰封末日生存沙盒。第一人称、WASD 操作、自由时间、探索与建造为核心乐趣。  
依据《融点_玩法与机制详案_v3.0.docx》实现，并按你的要求加入了**捕猎、交涉、组建团队、陨石天灾**等后期能力（文档口径中属后期项，此处一并做出可玩形态）。

## 一、运行方式

1. 安装 **Godot 4.2 或更新版本**（标准版，.NET 版亦可，本工程为纯 GDScript）。
2. 打开 Godot → 导入 → 选择本目录下的 `project.godot` → 导入并打开。
3. 按 **F5**（或右上角运行按钮）即可开始游戏。
4. 中文字体：由 autoload `InputSetup` 在启动时向 `ThemeDB.fallback_font` 注入系统中文字体
   （微软雅黑/黑体/Noto Sans CJK，Windows 与 macOS 均自动适配），无需任何外部字体文件。

## 三、开局（苏醒日）

黑屏 → 睁眼看到被削顶的冰封街道 → **按住 W 把腿从雪里拔出来** → 记忆闪回 →  
**亲手输入你的名字** → **选择职业**（医护/电工/教师/司机/厨子，决定随身工具）→  
自由沙盒开始。

第一天目标：**找一处能过夜的地方，留意别人的痕迹**。

- 街对面有**便利店**：小刀、剪子、背包、半冻饮料、火柴。
- 走不远有**保安亭**：整理床铺、门外生篝火，睡过第一个夜晚。
- 更远的**半塌门房**与**挡风墙根**可以占据为家。
- 街道两侧还会遇到**冰封民居**（双尖顶/平顶，屋里有床，可占为家）、**加油站**（罩棚+加油机+小卖部）、
  **小餐馆**（褪色红白雨棚）、**大仓库**（卷帘门+板条箱）与**水塔**；主干道是裂沥青补丁路面，
  积雪、褪色车道线与塌落块都铺在地形上（纯视觉，不会挡路）。

第一人称能看到自己的**手臂与手套**：空手时只显示手套，按 4 换出手里的工具
（小刀/长矛/扳手/手电……）会实时切换手持模型；E 交互出拳、捕猎突刺、下蹲收手。

## 四、玩法系统对照（设计文档 → 实现）

| 文档章节     | 实现                                                                              |
| -------- | ------------------------------------------------------------------------------- |
| 一、时间自由化  | 连续自由时间，无日程枷锁；昼夜/天气只影响体感与效率                                                      |
| 二、苏醒日    | 完整开场脚本：拔腿、记忆闪回、起名、职业、便利店、保安亭过夜                                                  |
| 三、周制天灾   | **泊松节奏模型**：λ 随季节查表（冬 0.15 / 初春 0.25 / 仲春 0.40 / 晚春 0.60 场·日⁻¹），最小间隔 T_min = 2.0 + 0.5×N；6 类天灾（陨石/尘云/暴风雪/暖春/冰震/远古微生物）+ 4 类复合，均带前兆窗口；强度每 15 日 +10%（StressMultiplier 1.0/1.2/1.5），不随庇护所等级放大 |
| 四、核心循环   | 秒级体感（冷饿乏→找柴水食→火/吃喝/睡）、日级探索、季级目标                                                 |
| 五、建造     | 以现成为地基（保安亭/便利店/门房/墙根/冰封民居可占据）；基础建材（水/石/木/冰雪砖）；幽灵放置；**系统判定庇护所 1-5 级**（避风窝→融点之家）；玩家无等级。**图纸系统**：随时把当前布局存为自绘图纸复用，或一键导入他人图纸（内置"火塘小屋/风雪堡垒"等预设），材料不足或重叠时整体拒绝、不留半拉子建筑 || 六、探索与幸存者 | 脚印与遗物先行登场；冰封的人搬到火边解冻；区域随距离解锁（三个区）                                               |
| 七、技能分期   | 手艺锚在随身工具与常识上，无经验升级；知识来自实物（图纸、首次捕猎解锁长矛做法）                                        |
| 八、随身物品   | 职业工具表 + 便利店搜刮底盘；用一次少一次                                                          |
| 九、团队     | 解冻→交谈→按条件加入（非好感度）；每人有状态/技能/个人需求；人多吃粮多；团队上限 = 2 + 庇护所等级                          |
| 十、温度     | 轻量体感链：环境/天黑/风/潮湿加速失温；火源/封闭/干燥/衣物回暖；**迟滞窗**（体感温度滞后真实体温）；轻中重三档只改手感                |
| 十一、结局    | 融点终端 + 多结局：熄灭/孤火/余烬之家/融点/未命名（真结局），由营地水平、同行者数、线索拼合度决定                            |
| 硬约束      | 单数人称状态文案；无战斗无血条无等级（捕猎为一次了结的"捕猎"而非战斗）；零传染（只有个体状态）                                |

## 五、剧情线索（为什么当年冰冻、如何解）

12 份散落的旧世界记录（便利店、废墟、二区、三区）拼出真相：  
**「白昼计划」轨道镜面实验招致异常极寒 → 月球被陨石撞碎、地表坑坑洼洼 →  
万年后气候改变、冰中人陆续解封 → 「融点计划」在地脉节点建聚热终端**。  
找齐 8 份以上，去**第三区点亮融点终端**，触发结局。

## 七、可调参数（改完即生效）

- **数值总源**：`scripts/data/design_values.gd`（`class_name DV`）——16 份设计文档的全部数值集中于此（时间尺度、视角手感、交互时长表、Cold Lag 四档、热力学常量、材质热阻、灾难泊松 λ 表、8 种资源属性、23 种建筑成本、74 项技能、疾病表、E 系 16 证据与三假说吻合度公式）。改这一个文件即可整体调参。
- 天灾间隔：`scripts/game.gd` → `disaster_interval`（默认 7 游戏日；设 168 即"现实一周"）
- 时间流速：`scripts/game.gd` → `MINUTES_PER_SECOND`（默认 2，一昼夜约 12 现实分钟）
- 世界种子：`scripts/game.gd` → `world_seed`（换一个数就是一整片新地貌）
- 世界大小/网格：`scripts/world/world_generator.gd` → `N` / `SIZE`

## 八、自检测试（改完代码跑一遍）

工程内置 6 个无头测试场景，命令行直接运行（退出码 0 = 全部通过）：

```
godot --headless res://smoke_test.tscn    # 冒烟：开场→建造→天灾→存读档→捕猎→图纸→结局（12 项）
godot --headless res://intro_test.tscn    # 开场链路：真实按键模拟 W×6→记忆→起名→职业→位移
godot --headless res://control_test.tscn  # 控制项：视角输入/面板拦截/下蹲/提示对比色/进屋/睡床
godot --headless res://reload_test.tscn   # 重载时序：F9 读档→旧 HUD 释放→持续通知（防 freed instance）
godot --headless res://content_test.tscn  # 内容：NPC/生物碰撞体与交互/路面/房屋/手部视图模型/拢雪
godot --headless res://systems_test.tscn  # 数值系统：热引擎tick/灾难λ/技能学习/建筑成本/证据吻合度/三结局（诊断写 user://systems_log.txt）
```

> **注意**：这些测试会写 `user://`（Windows 上是 `%APPDATA%\Godot\app_userdata\融点 RONGDIAN\`）。如果运行环境禁止写用户目录，`smoke_test` 的「存档」一项会假失败（exit 1 但代码本身没问题）。系统的诊断日志在 `user://systems_log.txt`，跑完可用 `.\debug.ps1 userdata` 直接打开该目录。

## 九、开发速查（debug.ps1）

仓库根目录的 [`debug.ps1`](debug.ps1) 把常用操作收成了一条命令（需要 PowerShell 7）。它会自己找 Godot，**不必把 Godot 加进 PATH**：

```powershell
.\debug.ps1 run                        # 直接开游戏窗口
.\debug.ps1 editor                     # 用 Godot 编辑器打开工程（断点/单步调试走这条）
.\debug.ps1 test                       # 依次跑上面 6 个测试并汇总 PASS/FAIL（失败退出码 1）
.\debug.ps1 test smoke                 # 只跑名字里含 smoke 的
.\debug.ps1 shot -Only 01,08 -NoHud    # 截图到 tools/shots/（13 个预设机位）
.\debug.ps1 probe probe8               # 跑 tools/probe8.tscn 这类数值探针
.\debug.ps1 scene Main                 # 无头跑任意场景
.\debug.ps1 userdata                   # 打开 user:// 目录（存档、日志）
.\debug.ps1 where                      # 只打印探测到的 Godot 版本与路径
```

探测顺序：`$env:GODOT_BIN` / `$env:GODOT4_BIN` → PATH 里的 `godot` → `D:\WorkSpace`、`D:\Godot`、`C:\Program Files` 等常见根目录下的 `Godot*` 目录。找不到或装在不常见的位置，就设一次环境变量：

```powershell
$env:GODOT_BIN = 'D:\Godot\Godot_v4.7-stable_win64.exe\Godot_v4.7-stable_win64.exe'
```

## 十、已知边界（原型取舍）

- 无音频（无外部素材依赖，全部程序化生成与代码绘制）。
- 生物为简单游荡/逃逸 AI；捕猎是一次了结的交互，不做血条与战斗。
- 建造为网格放置 + 系统判级，未做结构力学与精细热传导（文档明确砍掉）。
- 存档为 JSON（`user://rongdian_save.json`），保存世界种子并在读档后重建地形、建筑与同伴状态。
